### 快速与慢速候选

窗口左上角可选择 **快速 · 2.52 s** 或 **慢速 · 46.8 s**，默认快速。两种模式的 B210 硬件采样率始终为 204800 S/s；慢速增加硬件发送点数，保持原始 JT65 的符号时间和音调间隔。每帧仍承载 7 个有效比特，沿用同一同步、解调与 RS 纠错流程。

| 模式 | 正文时长 | 含空白每帧 | “约 1 分钟”预设 | 至少 1000 比特预设 |
|---|---:|---:|---:|---:|
| 快速 | 2.52 秒 | 2.92 秒 | 20 帧 / 140 bit / 58.4 秒 | 143 帧 / 1001 bit / 6.96 分钟 |
| 慢速 | 约 46.81 秒 | 47.22 秒 | 1 帧 / 7 bit / 47.22 秒 | 143 帧 / 1001 bit / 112.54 分钟 |

慢速发送一次完整 `hello` 需要自定义 **5 帧**，约 236.1 秒。速度切换会调整“约 1 分钟”的帧数；自定义次数保留，预计总时长可在底部提示或运行按钮提示中查看。录波回放自动按保存数据的实际速度显示。慢速是弱信号对照候选，加入该模式不代表已经通过 −20 dB 接收验收。

命令行也可使用 `jt65_capture_frames("hello",SpeedMode="slow")`，默认采集 1 帧；快速默认 20 帧。指定 `FrameCount` 可覆盖默认次数。

慢速候选验证（2026-10-16）：离线波形、硬件采样率往返转换后的编解码、界面速度切换与次数预设均已通过。一次 B210 实机采集完成 47.22 秒，目录为 `data/jt65_loop_20261016_000457_186/`；正文阶段记录 3 次发送欠载，接收无溢出、无空读，该帧未恢复字符，累计显示 `?`、失败 1 帧、未恢复 7 bit。此次不算成功的实机接收验证，也不构成 −20 dB 灵敏度验证；截图为 `data/jt65_slow_live.png`。

### 七比特整帧联合判决（128 候选）

窗口增加“译码：128 候选整帧联合 / 原 RS 硬判决”切换，默认联合判决，快速和慢速均可用。“解调与纠错”页显示全部 128 个候选的证据曲线、最佳候选和拒判门限；原 RS 保留用于相同录波、相同噪声种子的对照。旧 72 比特文字录波自动使用原 RS，不能套用七比特码本。

- 码本覆盖 **0–127 全部值**，逐个经过现有 RS(63,12)、交织及 Gray 映射，完全不以 `hello`、可打印字符或历史接收文字限制候选。
- 比较整帧 64×63 路相关能量，不先把每个数据符号压成一个硬判决。所有候选相同的补零符号不提供区分证据；公开同步时隙用于估计各数据频点的背景，降低持续单音干扰影响。
- 以固定功率比网格上的非相干混合似然评分，要求最佳候选的对数证据 ≥ `log(128/1e-6)`，且相对其余 127 个候选的总优势 ≥ 999 倍；任何条件不足均输出 **未恢复**。这两个门限只用于该候选译码器，原有同步搜索不变。
- 名义误报参数 `1e-6` 和模型后验不是实测误报率保证；有限背景估计、同步搜索和实际干扰会偏离理想模型。首次较宽门限在 3000 次噪声控制中误接收 1 次，因此收紧门限后用独立种子重新验证。
- 接收函数 `jt65_decode7` 只接受接收能量和背景功率，不接收发送参考。发送参考仅在判决完成后统计错误；未恢复、采集欠载及其他不连续帧保持失败/未知比特统计。

命令行回放：`exp34_jt65_live(ReplayDirectory="录波目录",DecoderMode="joint7")`。原命令行默认仍为 `hard`；界面默认选择 `joint7`。可用 `test_jt65_joint7` 复现码本及能量域控制测试，用 `exp34_jt65_joint7_compare` 复现完整同步链的录波加噪/慢速仿真 A/B；两者均不连接 USRP。能量域 SNR 结果假设已正确同步，不应当作完整接收链灵敏度。

### 连续采集与累计误码

实际 USRP 收发采样率为 204800 S/s（30.72 MHz / 150）。快速模式保留原始每符号 4096 点、每帧 126 个符号，共 516096 点，直接按硬件时钟播放，不再插值增加点数。因此每符号 20 ms，正文 2.52 秒，加保护空白每次 2.92 秒。默认循环 20 次，收发 58.4 秒，发送 140 个有效比特；设备启动和随后解码分析另需时间。这是加速 JT65 结构实验，音调频率和带宽也按 204800/11025 倍缩放，不是标准 JT65 空口时序。

循环采集以小块连续写入 `data/jt65_loop_时间/frame_编号/raw_iq.f32`（交替 I/Q、单精度、204800 S/s），整组结束后生成 `rx_capture.mat`：快速保持 204800 S/s；慢速经过滤波降采样恢复为 11025 S/s，用于同一接收算法分析，时长保持不变。两种模式的原始 IQ 均保留 204800 S/s，快速每帧约 4.8 MB、慢速约 77.4 MB，另保存参考波形与接收 MAT 文件。每帧保留欠载、溢出、空读计数；图表在整组采集后每分析 5 帧及最后一帧更新，采集时只更新进度和处理停止请求。

文字输入采用 7 位 ASCII，每帧发送一个字符并按输入顺序循环：`hello` 的 20 帧依次发送 `hellohellohellohello`。恰好 7 位的二进制输入则每帧重复该比特串。底部累计显示实际译码得到的文字；没有可靠输出的帧用 `?` 占位，不用发送参考补全。RS(63,12) 需要 72 位输入，因此额外补 65 个零；补位不计入有效载荷 BER。循环次数可调，设为 143 次时为 1001 个有效比特，但本次默认只运行约一分钟。旧文字录波按其原有 72 位口径回放。

累计结果保存在组目录 `cumulative.mat` 和 `cumulative.csv`：

- 译码前 BER = 各连续采样帧的 RS 码字硬判决错误比特之和 / 对应比特总数。
- 成功译码帧 BER = 连续采样且 RS 接受的帧中有效载荷错误比特之和 / 对应有效载荷比特总数（每帧 7 位）；不把失败帧当作 0 错误。
- 失败帧比例 = 未正确恢复消息或采集异常的帧数 / 总帧数。
- 未恢复消息比特单独计数，同时报告其全部正确/全部错误两种极端下的累计 BER 范围。采集异常帧不混入有效解调 BER。

### 同一帧的频域 SNR

加噪默认关闭。参考带宽可独立选择 400、2500、10000、20000 Hz，全部从带外噪声谱密度折算，不改变真实采样率或解调滤波。

先校正频偏，再对整帧 IQ 计算 Welch PSD（4096 点周期 Hann 窗、2048 点重叠、16384 点 FFT）：

- 令 `a = 采样率 / 11025`，新实验为约 18.576，旧录波为 1。
- 固定信号带：`[1255,1465] × a` Hz，宽 `210 × a` Hz，覆盖全部音调。
- 噪声参考带：`[1000,1230] × a` 和 `[1490,1720] × a` Hz，合计 `460 × a` Hz；与信号带各留 `25 × a` Hz 保护间隔。
- `N0 = 两侧噪声功率之和 / (460 × a)`。
- `Psignal = 信号带总功率 - N0 × (210 × a)`。
- `Pnoise(B) = N0 × B`，`SNR(B) = 10 log10(Psignal / Pnoise(B))`。

噪声来自正文同一帧的带外频谱，不再来自帧前后空白段。该方法假设两侧噪声密度能代表信号带内及参考带宽的噪声；带内干扰或有色噪声可能使估计偏差，不能保证在所有环境更准确。程序保存两侧密度差，超过 3 dB 时终端提示。20 kHz 是等效参考口径，不是直接测得 20 kHz 噪声。`Psignal <= 0` 时 SNR 为 NaN。

## JT65 实验三、四：纯 MATLAB 一键实时收发

在 MATLAB R2025b、单台 B210（3237C62）上实测通过。发射天线接 ch1 TX/RX，接收天线接同一通道的 RX2。先停止其他使用 B210 的收发程序，在 MATLAB 命令窗口执行：

```matlab
addpath('/Users/limit/Documents/MATLAB/USRP实验包/matlab/jt65_lab');
result = exp34_jt65_live("1011010");
```

`1011010` 可换成其他 7 位二进制数据；命令行仍兼容 1–9 个 ASCII 字符的旧文字实验。程序自动生成波形，识别唯一在线的 B210，启动收发并确认连续收到有效采样，留 0.2 秒空白后开始发送 2.52 秒的正文，继续收尾 0.2 秒，最后释放设备并自动解码。命令窗口每秒显示正文发送进度、已接收时长、接收电平、欠载和溢出次数。完整消息在收完一帧后显示。按 Ctrl+C 可中断，程序会释放收发对象。

默认中心频率 435 MHz、发射增益 30 dB、接收增益 40 dB。一次 20 dB 发射增益测试因接收信号变弱而未通过同步；将发射增益提高到 30 dB 后已实测恢复为符号、消息比特均零错误。这里的增益单位 dB 不是绝对输出功率 dBm，后者需要射频功率校准。若同时连接多台设备，可以指定：

```matlab
result = exp34_jt65_live("1011010", Serial="3237C62");
```

**同步得分门限已取消**：联合同步和旧版幅度搜索都会选取得分最高的候选，继续完成解调、逆格雷、解交织和 RS 译码。低同步得分不再报错退出，图中不再绘制门限线。低得分候选不代表同步已确认；是否正确恢复消息仍由 RS 状态和实际误码核对决定。

每次运行单独保存到 `data/jt65_live_时间/`，包含 `tx_reference.mat`、`rx_capture.mat`、`log.txt`、`result.mat` 和 `result.png`。`result.passed` 为真表示消息比特全部正确，且正文阶段未报告发送欠载、接收溢出或空读。2026-10-13 旧版 11025 S/s 首次完整实测：63 个符号全部正确、72 个消息比特全部正确，收发过程中无欠载、无溢出。

若只需重画已保存数据，可执行 `exp34_jt65_live(ReplayDirectory="某次采集目录的完整路径")`。该模式不连接射频硬件，新增图、日志和结果保存在原采集目录内的 `analysis_时间/`，保留原始记录。

### 接收信噪比极限测试（软件加噪）

`exp34_jt65_snr_test` 给已保存的真机 IQ 录波叠加复高斯白噪声，调用原接收程序重复测试。默认测 400 Hz 和 2500 Hz 参考带宽，SNR 从 −5 到 −30 dB，每档 20 次，采用当前接收程序（当前已取消同步得分拦截）。输出 `snr_report.mat`、`summary.txt`、`snr_sweep.png`。同步失败计入整帧失败，BER 只对实际产出译码比特的帧统计。

```matlab
report = exp34_jt65_snr_test("某次采集目录的完整路径");
% 需要细扫时可指定参考带宽、SNR 点和重复次数：
report = exp34_jt65_snr_test("某次采集目录的完整路径", ...
    Bandwidths=400, Levels=-11:-1:-14, Trials=30);
```

测试先用原始高信噪比录波估计信号功率和噪声功率，再设定所需额外噪声的方差。图中横坐标是这一校准目标，不采用低 SNR 下不稳定的帧内、帧外功率相减结果。测试只反映该条录波和当前程序在 AWGN 条件下的表现，不等同于新做的空口弱信号测试或标准 JT65 极限。

## 参数建议

- B210 USB3：先用 `rate=1e6`、`SamplesPerFrame=20000`、增益 20–40 dB。
- FM 广播：中心频率改成当地有台频点；本机实测 100.6 MHz 有强台。
- **双通道实验的默认频率已从 433 MHz 改为 100.6 MHz**：433 MHz 实测信号余量仅 5.6 dB（等同噪声），
  相干度会掉到 0.48，测出来的是两路噪声。100.6 MHz 下相干度 0.9977。
- 出现 overflow：降低采样率、缩短每帧、关闭实时绘图；出现削顶：降低 RX 增益。

## 本机天线实测

| 频段 | 余量 | 可用性 |
|---|---|---|
| FM 88–108 MHz | 30–49 dB | 强，天线主谐振区 |
| 137 MHz | 25 dB | 可用 |
| 915 MHz | 11.5 dB | 弱 |
| 1090 MHz (ADS-B) | 2.2 dB | 收不到，需 1090 MHz 专用天线 |

## 踩坑记录

以下问题均为实际运行验证，非推测。

### 1. MATLAB 无法运行以数字开头的脚本（致命，五个全中）

MATLAB `run.m` 最后一行是：

```matlab
evalin('caller', strcat(scriptStem, ';'));
```

它把**文件名当 MATLAB 代码求值**。`01_rx_spectrum` 被解析成数字 `01` 加非法标识符 `_rx_spectrum`，报
`Invalid text character`。对照实验：

| 文件名 | 结果 |
|---|---|
| `01_hello.m` | ❌ `Invalid text character` |
| `01hello.m` | ❌ `Unexpected 'hello'. Check for missing multiplication operator` |
| `aa_hello.m` | ✅ 正常 |

第二条的「缺少乘号」是铁证：MATLAB 把 `01hello` 当算式 `01 * hello` 解析。

**修复**：重命名为合法标识符，加 `exp` 前缀。绝对路径也无效（`run` 只取文件名部分），
MATLAB 也没有 `source()`（那是 Octave 的）。**只能改名。**

### 2. 含中文的 .m 文件需要 UTF-8 BOM

`00_find_usrp.m`、`04_jt65_codec_demo.m` 注释含中文。文件本身是合法 UTF-8，但 MATLAB 在 macOS 上
不认 locale（本机 `en_SG.UTF-8`），也自报 `DefaultCharacterSet: UTF-8`，却仍按非 UTF-8 解析。

**修复**：加 UTF-8 BOM（`EF BB BF`）。已验证：无 BOM 报错，加 BOM 后正常。
`exp00`、`exp04` 已加。

### 3. `run()` 会先 cd 到脚本所在目录

脚本里写 `audiowrite('data/xxx.wav', ...)`，经 `run('matlab/xxx.m')` 调用时，
`data/` 解析成 `matlab/data/`，该目录不存在 → 报 `Permission Denied`（**错误信息完全是误导**，
实际是目录不存在，不是权限问题）。

**修复**：用 `fileparts(mfilename('fullpath'))` 定位项目根目录并 `mkdir` 兜底。

### 4. FM 接收音频被拉长 1.68 倍（能听出来的 bug）

原 `02_fm_receive.m`：

```matlab
N=2^nextpow2(length(audio)); A=fft(audio,N); ... audio=real(ifft(A));
```

`ifft(A)` 返回 **N 点**而非原长度，数组被悄悄拉长。原长 1e7−1、`N=2^24=16777216`，
拉长比 1.6777。验算：`16777216 × 48000/1000000 = 805306.4 → 805307` 点，与实测 16.78 秒完全吻合。

**后果**：音频以 1.68 倍慢速播放，音调整体压低。

**修复**：记录 `n0=length(audio)`，滤波后 `audio=audio(1:n0)`。修好后输出正好 10.00 秒。

### 5. 鉴频前缺信道滤波（已补）

原脚本把整个 1 MHz 带宽直接送进鉴频器，而该带宽内含有多个 FM 电台（邻道间隔 100 kHz），
邻台会被一并解调出来。已补 `fir1` 低通（±100 kHz）后再鉴频。

### 6. 频谱脚本未排除 DC 尖峰（Python 侧，未改）

`python/02_spectrum.py` 取最强峰时未排除中心频点。B210 的直流跟踪通常会在中心留一个凹陷而非尖峰，
所以本例侥幸没出错，但换频点后可能把本振泄漏当成信号。建议取峰时排除中心 ±20 kHz。
